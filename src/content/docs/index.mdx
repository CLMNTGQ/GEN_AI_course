## A structured path through modern generative AI

This course moves from core machine-learning concepts to the internals of transformers, large-scale training, model adaptation, alignment, retrieval-augmented generation, agents, evaluation and responsible deployment.

<CardGrid stagger>
  <Card title="Understand" icon="open-book">
    Build a rigorous mental model of generative models, tokenization, embeddings and transformer architectures.
  </Card>
  <Card title="Adapt" icon="pencil">
    Compare prompting, fine-tuning, PEFT, LoRA/QLoRA and retrieval-augmented generation.
  </Card>
  <Card title="Evaluate" icon="rocket">
    Understand alignment, evaluation methodology, multimodality and the limitations of current systems.
  </Card>
</CardGrid>

## Course structure

The material is organized as a 20-hour learning path across eight modules, combining conceptual explanations, mathematical foundations, practical exercises and a group project.
